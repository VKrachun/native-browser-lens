Support

Write to lens@sirv.studio. Include what you did, what happened, and the output of lens doctor.

The side panel says "App not installed"

Lens needs its app on your computer. Download it, open it once, and the panel continues by itself. If the app is installed, open it again from your applications: it repairs its browser registration and opens the setup page.

Windows says "Windows protected your PC"

The Windows installer is not code-signed yet, so SmartScreen does not know it. Choose More info, then Run anyway. Lens installs for you only and needs no administrator rights. You can check the file against the SHA-256 sum shown on the download button.

Check the setup

In a terminal, run lens doctor. It checks each step (the app, starting at login, the browsers, the extension, a site to collect on) and says what to do for each open one. lens setup walks through them.

The lens command is the app itself: on macOS it is "/Applications/Sirv Lens.app/Contents/MacOS/lens", on Windows %LOCALAPPDATA%\Sirv Lens\lens.exe.

Adding the extension

  • Chrome, Edge, Brave: add Sirv Lens from the Chrome Web Store. Edge first asks to allow extensions from other stores. Without the store, open the extensions page (chrome://extensions), turn on Developer mode, choose Load unpacked and select the extension folder that the app's setup page names.
  • Firefox: add Sirv Lens from Firefox Add-ons. Without the store, open about:debugging#/runtime/this-firefox, choose Load Temporary Add-on and select extension-firefox/manifest.json. Firefox removes it when it closes; load it again after a restart.

Lens does not record a site

Open the site, open the Lens side panel and choose "Collect evidence on this site", then allow it when the browser asks. In Firefox, Lens also asks for access to all websites so that it can take screenshots; it still records only the sites you added.

My voice is not written down

Lens writes down speech on your computer with the Whisper model, a one-time download of about 575 MB. Download it from the side panel or from Settings. If the browser blocked the microphone, Lens opens a tab where you can allow it.

No title or findings appear

Lens writes them with Claude Code or Codex. Install one of them, sign in, and choose it (or Automatic) in Lens Settings, under AI model.

Removing Lens

Remove the extension from the browser. Then run lens service uninstall and lens unregister, delete the app, and, if you also want your recordings gone, the data folder named in the privacy policy.
